# Agent notes

UI / design-system work in this repo is coordinated between two agents (Claude and Codex) through files, not chat.

Before any UI, component, token or layout change, read:
1. `docs/design-system-v2/README.md` — program charter and the no-functional-change boundary.
2. `docs/design-system-v2/32_AGENT_COORDINATION_PROTOCOL.md` — roles, slice ownership, open questions, handoff log.
3. `docs/design-system-v2/31_VISUAL_DIRECTION_CONCEPT.md` — proposed visual direction and token values.

Claim a slice in `32` before working on it, and add a handoff-log entry when you stop.
