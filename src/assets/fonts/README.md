# Cairo font assets

These are unmodified WOFF2 files downloaded from the official Google Fonts CSS response on 2026-10-10 UTC. `../../styles/cairo.css` preserves that response's twelve face declarations, normal style, weights 400/500/600/700, `font-display: swap`, and complete Unicode ranges. Only the source URLs changed to local files. Google supplied the same binary for all four weights within each subset, so the three unique binaries are stored once. No conversion, manual subsetting, or preload was added.
