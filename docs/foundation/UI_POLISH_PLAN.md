3. القوائم والمخزون والمالية والائتمان: الجداول والفلاتر والإجراءات والعرض على الهاتف.
4. الموارد البشرية والعمل والأنشطة والزيارات: خطوات المهمة وتفاصيل السجلات وحالات الصلاحيات.
5. التقارير والإعدادات والإدارة والمصادقة والإشعارات: تخطيط الصفحات والحوارات والتنقل.
6. إغلاق مصفوفة التغطية على الهاتف والتابلت والديسكتوب، بما يشمل خطوات المهمة والحالات المتاحة.
