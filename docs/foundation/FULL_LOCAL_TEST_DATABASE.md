## الخدمات والعزل

Auth وREST وStorage وRealtime والبريد المحلي وKong تعمل على الشبكة الداخلية. بوابة nginx منفصلة فقط تصل الشبكة الداخلية بشبكة الوصول، وتنشر API على 127.0.0.1. قاعدة البيانات غير متصلة بشبكة الوصول. خدمات البيانات لا تملك خروجًا للإنترنت. cron غير نشط وطابور pg_net فارغ؛ إعدادات dispatch السحابية مستبدلة بقيم محلية معطّلة.

الدوال الخمس الحالية (create-user/admin-reset-password/cleanup-notifications/dispatch-notification/send-push-notification) جُمعت إلى bundles خارج المستودع دون تغيير المصدر، وتعمل في Edge Runtime على الشبكة الداخلية. نُزّلت الاعتماديات أثناء التجميع فقط؛ تشغيلها محلي دون تحميل اعتماديات من الإنترنت. الإرسال الخارجي للرسائل والإشعارات متوقف عمدًا، ولا نُثبت نجاح Web Push إلى أجهزة خارجية.

استخدم Realtime الإصدار المثبت نفسه الذي اجتاز فحص C3 الأخير، بدل إصدار CLI القديم. فحص مستقل أثبت اشتراك مستخدم مصادق ووصول INSERT فعلي إلى notifications، ثم حذف إشعار الاختبار. إخفاق الحدث على الإصدار القديم محفوظ خارج Git، ولا يُحذف من سجل التحقق.

Vite يعمل من فرع `codex/baseline-ui-polish`، مع تعطيل تحميل env الخاصة بالإنتاج وتعطيل PWA dev حسب إعداد المشروع الحالي، ومفاتيح محلية فقط. لذلك تظهر تغييرات المصدر حيًا على 5180. هذا ليس build إنتاجًا جديدًا ولا نشرًا سحابيًا.
